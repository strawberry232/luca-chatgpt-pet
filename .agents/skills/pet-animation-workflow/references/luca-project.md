# 卢卡最终版实例

仅用于本项目，其他角色不要套用其颜色或身体左右特征。由当前上下文定位项目，不按技能安装路径推断素材位置。

- `assets/luca-v2.png`：同步后从 Pets 回读的正式图集。
- `assets/source/rows/`：十一张最终可编辑行图，依序从 `00-idle.png` 到 `10-look-second.png`。
- `scripts/rebuild.py`：由最终行图重建，不依赖历史图集。
- `scripts/verify.py`：最终素材哈希、透明度、行图一致性、失落头发及投稿包检查。
- `scripts/package_petdex.py`：使用 `petdex/pet.json` 打包 v2 ZIP。
- `scripts/render_previews.py`：只从正式图集导出预览，MP4 可选依赖 OpenCV。
- `assets/previews/` 与 `qa/`：仅保留最终预览和当前检查。

先另存本次修改基准，只改目标行；确认差异后再更新哈希，不自动改哈希掩盖意外变动。需要完整侧身时，保持鼻口、躯干、短裤与鞋的侧面关系。棕发、灰黑横条纹、及膝短裤、浅色绑腿、黑短靴及左右不同纽扣眼需一致；绷带属于角色左臂，不能镜像换侧或重复。

失落复用待机头发和头部比例，仅作整数位移和表情变化。修复时检查上方头发像素，不用全图平均色证明一致。用户已授权本项目采用原图拆层；这不构成其他角色的自动授权。

用户已取消鼠标位置追踪。不要恢复网页跟随、128 帧补帧或相关脚本。v2 要求的十六方向仍作为图集姿态保留，客户端如何使用由客户端控制。眨眼时长不能由上传图集设置，半眨眼只改变幅度，不代表提速。九种动画不保证九条手动触发命令。
