# 保持造型一致的动画

## 原画与颜色

以用户认可的待机图或明确指定的新参考为准。记录材质色组、衣服轮廓、条纹分布、发型、眼睛和配件位置。不同视角的遮挡和光照不同，不要求所有像素相等；不能用全图平均色证明一致。量化配色时比较已知材质内部区域，排除半透明边缘和高光。

先修原画方向和服装语义，再做动作。及膝短裤不可变成长条纹裤；不要逐帧调色掩盖衣服画错。补侧面时提供正面参考、裤长、条纹约束和非对称特征，确定侧面后再批量出帧。

## 分层与关节

按实际原画拆分头、领口、身体、上下臂、手、骨盆/短裤、大腿、小腿和鞋。遮挡区补画保持同材质，不把手掌或袖口混入腿层。关节中心和层序按角色标定，不能套用卢卡坐标到其他角色。

肩带动上臂，肘弯曲带动下臂；髋带动大腿，膝带动小腿，踝控制脚。关节附近保留重叠以避免接缝，但仍需检查实际画面。非对称绷带固定在同一解剖侧，镜像不能使其换侧或重复。

统一渲染和采样，每帧复用确认的材质。用遮挡、位置和姿态表现远近；确需深度着色时按用户认可的统一光照处理，不随每帧切换腿的明暗。

## 跑步

八帧可以分配为：接触、压缩、蹬地、腾空、对侧接触、对侧压缩、对侧蹬地、对侧腾空。半周期错位不意味着所有角度可简单取反。肩髋配合、稳定屈肘、脚掌在接触/离地/摆动时方向不同。

先保证接触期支撑脚高度稳定、脚尖方向正确，再调腾空抬起和落地。检查膝反折、双脚交穿、手臂撞入身体和循环接缝。大幅上下漂浮不能代替步态。

完整侧身需要鼻口、头、躯干、短裤和鞋都有侧面依据。轻微正面倾斜加摆腿不满足该要求。

## 预览与判断

提供原尺寸 GIF/视频、两个方向关键帧、待机/左右跑并排对照。先验证未改非目标行，再评估观感。报告材质中位色差时说明取样范围，不扩大成所有颜色完全一致。分离块、绿边等检查同样说明阈值和限制。

仍不自然时依次定位原画、拆层、关节、接地和节奏，修改对应环节，避免反复整张重画。
