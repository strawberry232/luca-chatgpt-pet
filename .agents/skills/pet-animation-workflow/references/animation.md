# 按问题修复动画

## 跨动作造型一致性

出现动作切换后像换了角色、头部忽大忽小、发色或衣服变化时，先核对造型，再调整动作。

| 环节 | 处理方法 |
|---|---|
| 确定基准 | 新建宠物使用已确认的标准图；更新宠物使用当前确认的最终版本，通常以待机作为对照。 |
| 制作动作 | 优先复用已有素材；需要补画时同时参考标准图和相邻动作，避免逐帧独立设计角色。 |
| 处理侧身 | 允许合理的透视、光影与遮挡变化，保持服装图案、材质配色及不对称特征；不要求不同视角的轮廓完全相同。 |
| 检查一致性 | 将新动作与待机并排、按相同画布比例对照，核对头身比例、五官位置、发型发色、衣服结构及条纹走向，避免缩放预览掩盖头部大小差异。 |
| 修复差异 | 优先修正偏差部位，不用全图调色掩盖衣服画错；未经用户要求，不重新设计整套角色。 |

**通过标准**：切换动作时仍能识别为同一角色；除动作所需的表情、透视和光影变化外，没有无依据的头部变大、发色改变、服装换样或左右特征错位。合理的姿态变化不要求像素完全相同。

## 其他动作问题

- **跑步不自然**：按角色标定肩/肘、髋/膝/踝及层序，先修接地与遮挡，再调节奏。八帧可依次安排接触、压缩、蹬地、腾空及对侧四阶段；不能只让正面双腿摇摆来代替完整侧身。
- **关节或衣服穿帮**：在关节保留重叠和同材质遮挡补画，检查袖口、短裤与鞋。通过遮挡表现远近，不交替给腿染暗。非对称配件保持在同一解剖侧。
- **表情变成另一张脸**：复用同一头部、头发和身体，尽量只调整眼睑、嘴部及小幅姿态，不用缩放整头来表现情绪。
- **眨眼慢**：先查宿主时长控制能力。若固定时长，只增加过渡帧会延长动作；不能靠改预览速度宣称原生修复。需要完整闭眼时不要擅自改成半眨眼。

已有用户授权拆层时采用分层动画；否则遵循当前图像/Pets 技能的制作约束，不为新角色继承别的项目授权。

查看原尺寸循环及相关关键帧，必要时与待机并排对照。用材质内部取样评估色差，不以平均色或格式检查代替视觉判断。某个问题重现时调整对应的原画、拆层、关节、接地或节奏，不循环重做所有状态。
