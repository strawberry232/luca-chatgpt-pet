# 最终素材维护流程

[English](WORKFLOW.md)

以 `assets/luca-v2.png` 为发布基准，十一张最终行图保存在 `assets/source/rows/`。本仓库不保存旧图集、前后对比、阶段检查或鼠标追踪代码。

修复某个动作时先备份当前图集，锁定头型、发色、条纹、短裤、绑腿、鞋和左右特征；只修改目标行。缺侧面先补侧面，已有分层制作授权时复用固定纹理和关节动画。用逐行 RGBA 比较检查其余状态是否保留，再观看原尺寸循环。

运行重建、打包和检查脚本，检查 v2 布局、透明格、素材哈希、失落头发与待机原图一致性，以及 ZIP 的数字版本 2。通过后更新同一个宠物；下载回读核对画面，并将回读图集作为正式交付。同步后的 PNG 可能被平台重新编码，应分别核对字节和 RGBA 像素。

原生播放时长由客户端控制；调整 GIF 时长不会改变安装后的动画速度。不要把更快的预览或眼睑幅度变化说成原生客户端已经提速。最终预览由 `scripts/render_previews.py` 从正式图集导出；MP4 导出可选安装 OpenCV 并传入 `--mp4`。

具体制作可调用 `$pet-animation-workflow`。公开投稿和改变当前宠物选择按用户明确意图执行。
