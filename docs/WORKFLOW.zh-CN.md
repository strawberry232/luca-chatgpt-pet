用户提供的 MP4 约 82.37 秒，1920 × 1080、30 fps。分析时抽取 81 张采样帧，并检查关键位置的原尺寸画面。仓库不再分发原视频、原模型或其工程。

| 证据层级 | 内容 |
|---|---|
| 直接可见 | 头部转动与倾斜、眼皮与嘴形变化、表情特效、眼镜/面包/兽耳、键鼠区域的手部动作，以及表情列表、事件和设置界面。 |
| 作者字幕及界面 | 标示 Live2DViewerEX 与 BongoCat；字幕说明配件开关、独立动画按键和音量驱动嘴部。这是作者的说明，未读取对应源码。 |
| 合理推测 | 分层 Cubism 原画、参数、表情/动作资源和宿主输入映射可能构成原作架构；没有取得原参数 ID 或源工程。 |
| 视频没有确证 | AI 对话、语义理解、桌面行走、语音合成、精确的输入触发关系及音量与口型同步效果。 |

## 本项目实际流程

1. 确定待机造型：棕发、左右不同的纽扣眼、灰黑条纹服装、及膝短裤、浅色绑腿和黑靴。
2. 制作九种状态与十六个注视方向。修改某个动作时保留已经认可的其他行。
3. 参照待机图生成一对真正 90° 侧身原画，按待机图对头发、皮肤、衣服、眼睛等材质进行一次配色校准。校准后的原画保存在 `assets/source/`。
4. 按用户明确选择的“原图拆层动画”方案，拆分头、领口、身体、上下臂、大腿、小腿和鞋；被遮挡的小范围衣服区域用相邻同材质颜色补齐。
5. 按肩/肘和髋/膝/踝的层级关系生成每方向八个姿态。绷带保持在真实左右手臂；所有帧复用固定纹理，通过图层遮挡表现远近，并对支撑脚与腾空阶段进行对齐。
6. 只替换图集第 1、2 行。待机、挥手、跳跃、失落、等待、工作、检查成果和十六方向保持原样。
7. 检查图集尺寸、透明度、有效格、绿边与连续性；查看原尺寸 GIF、跑步关键帧及待机/跑步对比。检查结果记录在 `qa/`。
8. 在支持的 Pets 环境中验证、上传并更新指定宠物，保留其身份。是否启用另行选择；此仓库不含账号宠物 ID 或签名上传链接。

## 工具、skills 与插件各自负责什么

| 工具 | 用处与边界 |
|---|---|
| ChatGPT | 分析参考、描述造型约束、规划动作、评审预览。 |
| Codex + Python/Pillow/NumPy | 拆层、关节动画、图集合成、逐像素检查及中英文项目整理。 |
| imagegen 技能/图像生成 | 生成定稿原画与缺少的侧面。逐帧独立重画容易导致配色和衣服漂移，因此最终跑步固定使用两张原画。 |
| Pets 插件 `work-pets` | 在支持的 ChatGPT Work 环境中创建、更新、验证和预览宠物；不能直接导入 Live2D 模型，也不提供任意关键词触发。 |
| GitHub 插件 / 官方 GitHub CLI | 保存素材、源码、文档与版本记录，不控制宠物动作播放。 |
| Live2D Cubism / Live2DViewerEX / BongoCat | 后续另做桌面 Live2D 版时再使用，不是当前图集的运行依赖。 |

相关 Pets 技能包括 `create-pet`、`update-pet` 与 `pets`；图像制作使用 `imagegen`。制作当前版本不需要额外安装 Figma、Adobe 或 Godot。重建操作见首页。此绑定针对附带的两张原画，不是任意角色通用的自动绑定器；大幅修改造型仍需补画与视觉检查。
